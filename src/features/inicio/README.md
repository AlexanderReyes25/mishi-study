# Inicio

`InicioView.tsx` presenta los accesos a Materiales, Repaso y Progreso, la sombra de Mishi y el cierre de sesión. La ruta `src/app/(tabs)/index.tsx` conecta esos accesos a Expo Router.

Progreso está en `src/features/progreso/`, con consultas reales en `src/services/dashboard.ts`. Los antiguos componentes `Prueba*` se retiraron; sus servicios siguen conectados a Materiales y Práctica libre.
